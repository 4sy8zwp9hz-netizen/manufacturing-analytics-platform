Operational definitions

Cycle time is event end minus event start. Queue time is the next operation start minus the previous operation end for the same wafer. Route elapsed time is final event end minus first event start. Throughput means observed completions per period and tool; utilization is intentionally omitted because no capacity calendar or equipment-state model exists.
